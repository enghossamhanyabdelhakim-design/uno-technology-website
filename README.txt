Uno Technology Services website / موقع أونو

UPLOAD / الرفع: upload this whole folder (index.html, tools.html, blog.html, admin.html, assets/) to any static host (Netlify, GitHub Pages, Cloudflare Pages). No build step.

EDIT CONTENT / تعديل المحتوى: open /admin.html, edit any text, image, link, service, blog post or chatbot answer, press Preview, then Export. Replace assets/content.js with the exported file and upload again.
NOTE: admin.html has no password. It cannot change the live site by itself: changes only go live when you upload the exported content.js. For real logins and saving online you need a backend service (see the report).
